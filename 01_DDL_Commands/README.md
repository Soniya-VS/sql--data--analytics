# Assignment 1 – DDL Commands & Constraints

This assignment focuses on SQL DDL (Data Definition Language) commands and
constraints using MySQL.

## Topics Covered

- CREATE DATABASE
- CREATE TABLE
- ALTER TABLE
- ADD, MODIFY and DROP columns
- RENAME TABLE
- TRUNCATE TABLE
- DROP TABLE
- DROP DATABASE
- PRIMARY KEY
- NOT NULL
- UNIQUE
- CHECK
- DEFAULT
- AUTO_INCREMENT
- FOREIGN KEY

## Database Structure

The assignment uses an `employee` database containing:

- Departments
- Location
- Employees

The Employees table is connected to the Departments and Location tables
using foreign keys.

## Tools Used

- MySQL
- MySQL Workbench
