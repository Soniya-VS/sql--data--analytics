# Assignment 2 – Data Querying, Sorting, Aggregation & Joins

This assignment focuses on querying and analyzing data in MySQL using
DML and SQL query commands.

## Topics Covered

- SELECT
- DISTINCT
- Column Aliases
- WHERE
- NULL values
- UPDATE
- ORDER BY
- LIMIT
- Aggregate Functions
- GROUP BY
- HAVING
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN

## SQL Concepts Practiced

The assignment demonstrates how to:

1. Retrieve unique salary values using `DISTINCT`.
2. Rename columns using aliases.
3. Filter records using `WHERE`.
4. Identify and update missing values.
5. Sort data using `ORDER BY`.
6. Limit query results using `LIMIT`.
7. Calculate totals and minimum values using aggregate functions.
8. Group data using `GROUP BY`.
9. Filter grouped results using `HAVING`.
10. Combine related tables using SQL JOINs.

## Database Tables

The queries use the following tables:

- Departments
- Location
- Employees

The `Employees` table contains employee details such as name, age,
gender, designation, hire date, department, location, and salary.
